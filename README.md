# DevFlow

Frontend em React + Vite para o sistema interno de gestao de desenvolvimento.

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:8022](http://localhost:8022).

## Variaveis

Copie `.env.local` e ajuste:

```env
PORT=8022
NEXT_PUBLIC_API_URL=http://localhost:4011/api
```

## Build

```bash
npm run build
npm run start
```

O backend fica no diretorio `backend/`.
